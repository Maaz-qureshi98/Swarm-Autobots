# Reproducing the results

All results are stored as JSON in `sim/results/` and regenerated by the scripts
below.

```bash
pip install -r requirements.txt
make experiments   # optional: rerun all simulations (30-60 min, two cores)
make figs          # figures + results/stats.json + results/stats_tests.json
make test          # agent and ROS graph tests
```

## Experiment map

| Script call | Output | Used for |
|---|---|---|
| `experiments.py e1` | `e1_loss.json` | loss sweep (`fig_loss` a, b), formation-results table |
| `experiments.py e1b` | `e1b_burst.json` | burst-length results |
| `experiments.py e2` | `e2_safety.json` | unmapped obstacles (`fig_safety`) |
| `experiments.py e3` | `e3_election.json` | leader-failure results |
| `experiments.py e3x` | `e3_example.json` | one leader-failure run (`fig_election`) |
| `experiments.py e4` | `e4_scale.json` | scalability (`fig_loss` c, d) |
| `experiments.py e5` | `e5_drift.json` | trajectories (`fig_traj`), drift numbers |
| `experiments.py e6` | `e6_switch.json` | pattern-switching text |
| `experiments.py e7a e7b` | `e7_consensus_*.json` | consensus baseline |
| `sensitivity.py` | `sensitivity.json` | election timeout and barrier-rate sweeps |
| `stats_tests.py` | `stats_tests.json` | Wilcoxon tests, success-threshold check |
| `mismatch.py` | `e8_mismatch.json` | model-mismatch table |
| `mismatch_compass.py` | `e8b_compass.json` | compass-bias sweep |
| `e9_review.py` | `e9_review.json` | component ablation, prediction-bound check, hardware-scale runs |
| `e12_calib.py` | `e12_calib.json` | idealized prediction-bound check, compass/slip calibration |
| `e13_footprint.py` | `e13_footprint.json` | collision studies with the 0.14 m circumscribed footprint (`fig_safety`, ablation table, lambda sweep, Table I collision check) |

Every condition uses 100 missions (40 for scalability) with common random
numbers across methods, so the tests are paired by mission.

## Figures

| Script | Output |
|---|---|
| `make_figs.py` | `fig_loss`, `fig_safety`, `fig_election`, `fig_traj`, `fig_drift` |
| `make_robot_fig.py` | `fig_robot` (robot, sensor layout, wiring) |
| `make_teaser.py` | `fig_teaser` (robots and leader recovery) |
| `make_cases_fig.py` | `fig_cases` (hardware, simulation, and ground truth for the four cases) |
| `make_sim_videos.py` | labelled simulation videos (obstacles, leader failure, pattern switch) |
